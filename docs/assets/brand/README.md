# Brand and decorative assets

- `nus-horizontal.jpg`: supplied NUS mark, reused without redrawing from the FilmTogether technical-report source. CSS crops only its existing white padding.
- `cinema-backdrop.jpg`: decorative background generated with the built-in ImageGen tool for the selected website concept, 1586 × 992 pixels. It is **not** a dataset sample or a FilmTogether model output. All video players and thumbnails continue to use the original showcase media.

Generation prompt: Empty realistic midnight-navy screening room, palette near `#061626` and `#003D7C`, faint acoustic architecture and amber details at the extreme sides, tiny top-corner spotlights, calm dark central 85% with ample negative space for HTML headings and real video players. No screens, people, text, UI, logos, video scenes, neon, or curtains.

The original generated PNG is preserved outside this public site. The JPEG is a compressed web export.

UI icons are Bootstrap Icons 1.13.1, distributed under the MIT license in `../icons/LICENSE.txt`.
